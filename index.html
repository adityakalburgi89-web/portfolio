NexTradeX — Real-Time Crypto Mock Trading & Risk Simulation Engine

A high-throughput cryptocurrency paper trading and financial risk simulation engine supporting perpetual futures, options settlement, automated DCA strategies, and real-time market data failover.

Architecture & Key Features:
  • High-Availability Data Pipeline: Architected a 3-tier external API failover engine (Binance → Bybit → MEXC) with symbol/global cooldown circuit breakers and adaptive interval translation, achieving 99.99% market data feed uptime during API rate-limit periods.
  • Distributed Rate Limiting: Built a custom Spring @RateLimit interceptor executing atomic Redis Lua scripts (token-bucket algorithm) with a fail-safe bypass mechanism to protect endpoints against burst traffic.
  • Order Engine & Financial Risk Math: Engineered a multi-threaded order matching engine and risk liquidation service supporting up to 125x leverage perpetual futures, options settlement, and automated DCA schedules with zero float precision loss using BigDecimal.
  • Transactional Ledger & Concurrency: Implemented isolated multi-currency wallet ledgers (SPOT, MARGIN, FUTURES) utilizing ACID database transactions to lock funds upon order creation and prevent double-spending race conditions.
  • Real-Time UI & Telemetry: Integrated STOMP WebSockets streaming live candlestick charts using Lightweight Charts and deployed containerized Prometheus & Grafana dashboards to monitor JVM memory, connection pools, and execution latency.
Tech Stack: Java 17, Spring Boot 3, React 18, Redis, PostgreSQL/H2, WebSockets (STOMP), Prometheus, Grafana, Docker, Tailwind CSS
